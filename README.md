# Mindscape

本地优先的 macOS 思维导图应用。Swift 原生开发，数据保存在本机 SQLite，不联网、不需要账号。

当前版本：**0.3.0**

## 技术栈

| 层 | 实现 |
|---|---|
| UI | SwiftUI + AppKit |
| 画布 | 自绘 `NSView`（Core Graphics，非 Web 渲染） |
| 图标 | SF Symbols（系统图标库，无第三方依赖） |
| 数据 | 系统 `libsqlite3`，WAL 模式，无第三方依赖 |
| 工程 | XcodeGen（`project.yml` 是唯一工程描述） |
| 最低系统 | macOS 14 |

## 已实现

**画布与节点**
- 无限画布：双指平移、捏合缩放、⌘ + 滚轮缩放、适配画布
- 节点：新增 / 删除 / 重命名 / 折叠 / 拖动 / 多选
- 拖动节点：
  - 拖到另一个节点上 → 挂到该节点下面
  - 按住 ⌥ 拖到同级节点的上 / 下位置 → 调整兄弟顺序
  - 拖动时目标节点显示虚线高亮
- 双击或 F2 就地编辑，Enter 提交，Esc 取消，Shift+Enter 换行；选中节点后直接打字也可以开始编辑
- 编辑时文字位置与画布一致，超出宽度自动换行，节点随内容扩展
- 编辑节点时隐藏画布原文，避免输入框与节点文字重影
- 节点备注、SF Symbols 图标（102 个，可按含义搜索、滚动浏览、收起）、自定义颜色
- 方向键在节点之间跳转
- 右侧属性面板分区展示（文字、备注、图标、颜色、操作），按钮统一尺寸、图标靠右
- 右侧属性面板收起：窗口右上角固定按钮或 ⌥⌘I（只有一个可见开关）
- 设置页改为侧栏式布局：通用 / 快捷键 / 关于，与主界面同一套配色和卡片样式

**布局（8 种）**
- 思维导图（左右平衡）
- 逻辑图（右 / 左）
- 组织架构图
- 树形图
- 时间轴
- 括号图
- 自由布局

**主题（8 套）**
- 纸白、深空、莫兰迪、商务蓝、蓝图、霓虹、暖砂、墨线
- 切换主题只换视觉，不改结构

**文件树**
- 左侧目录树，支持多级目录
- 新建目录 / 子目录、重命名、删除（删除目录时内容会移到上一级，不丢数据）
- 文档拖到目录上即可归档
- 右键「移动到」也可以整理
- 搜索、收藏、回收站、恢复、彻底删除

**数据与历史**
- SQLite 自动保存（600ms 防抖）
- 撤销 / 重做（150 步）
- 手动快照 + 每 10 分钟自动快照（自动快照保留 20 份）
- 历史版本回滚，回滚前自动留档
- 数据目录可在「设置 → 通用」中更换，切换时自动复制现有数据
- 启动时显示最近打开的导图

**快捷键**
- 设置里可以逐个重新录制快捷键
- 菜单快捷键至少需要一个 ⌘ / ⌥ / ⌃ 修饰键，避免和输入冲突
- 冲突检测、单项恢复默认、全部恢复默认
- 节点类快捷键只在画布获得焦点时生效

**导入导出**
- 导出 PNG（1x / 2x / 3x）、PDF、Markdown、OPML、JSON
- 系统分享：AirDrop、邮件、信息等（导出面板直接分享）
- 目录右键「导出为」可快速保存单个导图
- 模板：空白、项目规划、会议纪要、读书笔记、SWOT、周计划

## 目录与数据

默认目录：

```
~/Library/Application Support/Mindscape/mindscape.sqlite
```

可以在「设置 → 通用 → 数据目录」中更换。切换规则：

- 目标目录为空：把当前数据库复制过去，然后切换
- 目标目录已有 `mindscape.sqlite`：直接打开其中的导图，原目录数据不删除

表结构：

- `documents`：文档元信息 + 完整导图 JSON + 所属目录
- `folders`：目录树
- `snapshots`：历史快照 JSON
- `settings`：预留键值配置

文档主体用 JSON 存储（保存快、天然适合快照），列表和搜索所需的标题、布局、主题、节点数、目录冗余成列。

## 运行

```bash
# 安装工程生成器（只需一次）
brew install xcodegen

make run             # 生成工程、编译、启动
# 或
xcodegen generate
open Mindscape.xcodeproj
```

构建产物在 `build/Build/Products/Debug/Mindscape.app`。

打包与本地安装：

```bash
make package    # 生成 dist/Mindscape-0.3.0.dmg 和 .zip
make install    # 安装到 /Applications 并启动
```

当前是 ad-hoc 签名，适合本机使用；对外分发需要 Developer ID 签名和 notarization。

```
    └── Assets.xcassets/        # AppIcon / BrandMark
```

## 设计约定

- 画布**自绘**：节点与连线走 Core Graphics，缩放时直接变换坐标系，避免大量 SwiftUI 视图带来的性能问题。
- 布局引擎是纯函数：`MindMap -> LayoutResult(frames, bounds)`，渲染和导出复用同一份结果。
- 编辑状态集中在 `MapEditor`（`@Observable`），画布、属性面板、工具栏都读写它；保存与撤销只在 Editor 里发生。
- 节点图标使用 SF Symbols 名称存储，渲染时按主题文字色着色。
- 主题只影响画布，窗口 chrome 跟随系统外观。
- 目录删除采用「上移内容」而不是级联删除，避免误删。

## 已知限制 / 下一步

- 尚未支持导入（Markdown / OPML / FreeMind / XMind）
- 还没有大纲视图、演示模式、专注模式
- 没有关系线、概要、附件、图片节点
- 自由布局只能手动摆放，暂无网格吸附
- 目录支持拖入文档，但目录本身还不能拖动排序
- 尚未做滚动备份、导入导出冲突检测
- 未签名 / 未公证，只适合本机开发运行

建议下一阶段：大纲视图 → 演示模式 → 全文搜索（FTS5）→ 导入 → 附件。
